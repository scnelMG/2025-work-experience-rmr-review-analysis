# 데이터 공개 기준

이 디렉터리의 CSV·XLSX 원본과 전처리 파일은 GitHub에 올리지 않습니다. 원본 리뷰에는 작성자 식별 가능 필드와 사용자 작성 내용이 포함될 수 있고, 전처리·집계 파일도 공개 적절성을 별도로 검토해야 합니다.

## Drive 원본 보관

원본 보관과 Drive 업로드에는 이 디렉터리를 포함합니다. 데이터는 파일 구조를 유지한 채 보관하되, 외부 공유 링크는 최소 권한으로 설정하세요.

## 공개 재현이 필요할 때

공개용 샘플이 필요한 경우에만 아래를 모두 충족한 최소 데이터셋을 별도로 만드세요.

1. 작성자·작성자정보·식별 가능 주문 정보 등 직접 식별 필드를 제거한다.
2. 원문 리뷰는 재배포 가능 여부를 확인하고, 필요하면 집계 결과만 제공한다.
3. 추출 기준과 비식별화 기준을 문서화한 뒤 검토한다.
